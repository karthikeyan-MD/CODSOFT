# 💳 Credit Card Fraud Detection using Machine Learning

## 🚀 Project Overview

This project focuses on detecting fraudulent credit card transactions using machine learning algorithms.
It simulates real-world fraud detection scenarios with imbalanced data.

---

## 🎯 Objectives

* Detect fraud transactions
* Handle imbalanced datasets
* Compare multiple ML models
* Improve fraud detection accuracy

---

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* TensorFlow (for image validation)

---

## ⚙️ Workflow

1. Data Preparation
2. Handling Imbalanced Data
3. Model Training (Logistic Regression, Random Forest)
4. Model Evaluation
5. Fraud Prediction System
6. Image-based Credit Card Validation (Bonus Feature)

---

## 🤖 Models Used

* Logistic Regression
* Random Forest Classifier

---

## 📊 Results

* High accuracy achieved
* Improved fraud detection using Random Forest
* Focus on recall for fraud cases

---

## 🔍 Bonus Feature (Deep Learning)

* Upload an image
* Detect whether it is a credit card or not
* Built using pretrained deep learning model

---

## ▶️ How to Run

1. Open notebook in Google Colab
2. Run all cells
3. Test fraud prediction
4. Upload image for card detection
