# 📩 Spam SMS Detection using Machine Learning

## 🚀 Project Overview

This project focuses on building a Machine Learning model to classify SMS messages as **Spam** or **Not Spam (Ham)**.
It uses Natural Language Processing (NLP) techniques to process text data and predict message categories.

---

## 🎯 Objectives

* Detect spam messages using ML algorithms
* Apply text preprocessing techniques
* Convert text into numerical features using TF-IDF
* Build an explainable model for better understanding

---

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Matplotlib

---

## 📂 Dataset

* SMS Spam Collection Dataset
* Contains labeled messages (spam/ham)

---

## ⚙️ Workflow

1. Data Loading & Cleaning
2. Text Preprocessing (removing special characters, lowercasing)
3. Feature Extraction using **TF-IDF**
4. Model Training using **Logistic Regression**
5. Model Evaluation (Accuracy, Precision, Recall, F1-score)
6. Prediction System with Explainability

---

## 🤖 Model Used

* Logistic Regression
* TF-IDF Vectorizer for feature extraction

---

## 📊 Results

* Achieved high accuracy (~95%+)
* Efficient classification of spam messages
* Balanced performance using precision and recall metrics

---

## 🔍 Unique Feature (Explainability)

The model provides insights into:

* Important words influencing predictions
* Transparency in classification decisions

---

## 💡 Additional Features

* Real-time SMS prediction using user input
* File-based prediction using uploaded `.txt` files

---

## ▶️ How to Run

1. Upload dataset (`spam.csv`)
2. Run the notebook in Google Colab
3. Train the model
4. Enter SMS manually or upload a `.txt` file for prediction
